# data/raw — документы, которые не публикуются

Сюда кладут PDF, которые нельзя выкладывать в открытый репозиторий: паспорта и руководства
производителей, тексты стандартов. Папка исключена из Git (см. `.gitignore`), кроме этого файла.

После добавления файлов пересоберите базу: `uv run ingest.py`.

Примеры публичных документов Sigur, которые можно скачать вручную с сайта производителя:

- https://sigur.com/dl/SigurAdminGuide.pdf — руководство администратора;
- https://sigur.com/dl/Sigur_E500U_E900U_R500U_R900U.pdf — руководство по контроллерам;
- https://sigur.com/doc/Sigur_MR1_install.pdf — руководство по монтажу считывателя MR1.
