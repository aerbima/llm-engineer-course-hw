# FAQ проектировщика СКУД

> Учебный документ. Вымышленные ответы на частые вопросы для домашнего задания по RAG.

## Какую версию Revit использовать для новых проектов?

Новые проекты раздела СКУД ведут в Revit 2024. Переход на другую версию в ходе проекта согласуют с ГИП.

## Где взять семейства оборудования?

Семейства оборудования берут только из корпоративной библиотеки в CDE, папка «Библиотека/СКУД». Скачивать семейства с сайтов производителей и сразу ставить их в модель нельзя: сначала их проверяет BIM-координатор.

## Как получить тип точки доступа для двери?

Тип точки доступа (ТД-1 … ТД-4) определяют по назначению помещения и по тому, лежит ли дверь на пути эвакуации. Список типов и их состав приведён в СТП-СКУД-01, раздел 2.

## Что делать, если заказчик требует длину линии Wiegand больше 50 м?

Объяснить заказчику ограничение СТП-СКУД-01 (пункт 4.1) и предложить считыватель с интерфейсом RS-485 или дополнительный контроллер. Отступление от стандарта возможно только с письменного разрешения ГИП.

## Кто отвечает за кабельный журнал?

Кабельный журнал формирует проектировщик раздела. Длины считают по трассам на планах с запасом 10 % (СТП-СКУД-01, пункт 4.6).

## Можно ли передавать модель Revit заказчика во внешние онлайн-сервисы?

Нет. Модели и документация по системам безопасности объекта — конфиденциальные сведения. Их нельзя загружать во внешние онлайн-сервисы, в том числе в публичные чат-боты на основе языковых моделей. Для работы с документами используют только корпоративный ассистент, который работает внутри компании.

## Сколько длится выпуск комплекта после передачи на проверку?

По регламенту РЕГ-ПД-02: проверка инженером-проверяющим — до 3 рабочих дней, нормоконтроль — до 2 рабочих дней. Итого — до 5 рабочих дней без учёта времени на исправление замечаний.
