# РЕГ-ПД-02. Регламент выпуска проектной документации отдела слаботочных систем

> Учебный документ. Вымышленный регламент для домашнего задания по RAG.

## 1. Общие положения

1.1. Регламент определяет порядок проверки и выпуска рабочей документации разделов СКУД, СОТ (видеонаблюдение) и АПС (пожарная сигнализация).

1.2. Документацию выпускают только из общей среды данных проекта (CDE). Отправлять заказчику файлы с локального диска запрещено.

## 2. Этапы выпуска

2.1. Документация проходит четыре этапа: разработка, самопроверка, проверка инженером-проверяющим, нормоконтроль.

2.2. Самопроверку проектировщик выполняет по чек-листу ЧЛ-СКУД. Заполненный чек-лист прикладывают к комплекту в CDE.

2.3. Срок проверки инженером-проверяющим — не более 3 рабочих дней с момента передачи комплекта.

2.4. Срок нормоконтроля — не более 2 рабочих дней. Нормоконтролёр проверяет оформление по стандартам СПДС, но не проверяет технические решения.

2.5. Замечания фиксируют в реестре замечаний проекта. У каждого замечания есть номер, автор, ссылка на лист и пункт нормативного документа или стандарта.

2.6. Замечание без ссылки на источник считают рекомендацией: проектировщик вправе его не исполнять, но обязан ответить в реестре.

## 3. Именование файлов

3.1. Имя файла комплекта: «<шифр проекта>-СКУД.<номер изменения>», например «АБ-2026-014-СКУД.0» для первого выпуска.

3.2. Модель Revit раздела называют «<шифр проекта>_СКУД_<версия Revit>.rvt», например «АБ-2026-014_СКУД_R2024.rvt».

## 4. Изменения после выпуска

4.1. Изменения в выпущенной документации вносят только через извещение об изменении.

4.2. Номер изменения увеличивают на единицу при каждом новом выпуске комплекта.

4.3. Если изменение затрагивает обозначения точек доступа, к извещению прикладывают ведомость перенумерации по СТП-СКУД-01, пункт 7.3.

## 5. Ответственность

5.1. За технические решения отвечает проектировщик раздела, за полноту проверки — инженер-проверяющий, за оформление — нормоконтролёр.

5.2. Подпись ГИП на титульном листе ставят после закрытия всех замечаний со ссылкой на источник.
