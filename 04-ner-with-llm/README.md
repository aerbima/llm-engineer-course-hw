# NER with YandexGPT

Проект для извлечения именованных сущностей (NER) из юридических текстов с использованием YandexGPT.

## Структура проекта

| Файл | Что делает | Пункт задания |
|------|------------|---------------|
| config.py | Ключи из .env, параметры генерации, лимиты длины | 1, 3 |
| load_samples.py | Скачивает тексты из russian-legal-ner | 1 |
| data_prep.py | Очистка, проверка длины, chunking | 1 |
| prompts.py | Системный и пользовательский промпт, few-shot пример | 2 |
| llm_client.py | Запрос к API через requests, повтор при перегрузке | 3 |
| llm_parser.py | Очистка от Markdown, json.loads, проверка структуры и опоры на текст | 2, 3 |
| pipeline.py | Прогон всех документов, сохранение JSON | 3, 4 |
| report.ipynb | Отчёт: промпты, примеры, ошибки, выводы | 5 |

## Используемые библиотеки

| Библиотека | Зачем |
|------------|--------|
| requests | HTTP-запросы к API |
| python-dotenv | Читать ключи из .env |
| pydantic | Проверять структуру JSON по схеме |
| datasets | Скачать russian-legal-ner с Hugging Face |
| pandas | Сводная таблица в отчёте |
| ipykernel (dev) | Ядро Jupyter для ноутбука |

## Структура каталогов

- `data/docs/` — исходные документы для обработки.
- `results/` — JSON-файлы с результатами извлечения сущностей.
