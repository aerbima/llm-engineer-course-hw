# LLM Engineer Course Homework

Homework assignments completed during the "LLM Engineer" course (OTUS).

## Assignments

| Folder | Topic | Report |
|---|---|---|
| [04-ner-with-llm](04-ner-with-llm/) | Named entity extraction (NER) from Russian legal documents with the YandexGPT API: prompt engineering, JSON validation, hallucination checks | [REPORT.md](04-ner-with-llm/REPORT.md) |

## Assignment structure

Each assignment folder contains:

- source code;
- `README.md` with setup and run instructions;
- a report (`REPORT.md` or a Jupyter notebook);
- results and screenshots (when applicable).

API keys and other secrets are not committed: each assignment has a `.env.example` template, the real `.env` is ignored by Git.
